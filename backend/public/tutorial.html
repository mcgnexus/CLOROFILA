Qué es esta aplicación

Un gemelo digital simplificado para medir clorofila con el sensor espectral AS7341 (11 canales: F1–F8, Clear y NIR). El sistema simula una hoja, predice qué debería medir el sensor con el modelo físico PROSPECT-D y compara ambas señales en tiempo real.

Todo lo que ves son datos sintéticos: sirven para aprender y demostrar el sistema, no son un diagnóstico agronómico.

El dashboard, pieza a pieza

  • Gráfico de espectro: barras = lectura simulada del sensor; línea = predicción del gemelo. Si se separan, algo cambia en la hoja (o en tu supuesto).
  • Comparación (RMSE, error relativo, sesgo): cuánto se aparta la lectura del modelo, en cuentas ADC.
  • Indicador 0–100: normalización demostrativa del Cab supuesto. Cab estimado (ML): lo que deduce un modelo Ridge entrenado con 10.000 hojas sintéticas (solo en reflectancia).
  • Hoja simulada: el estado «verdadero» (desconocido en campo; aquí visible para aprender). Deriva lentamente para que el panel se vea vivo.

Controles y utilidades

  • Sliders Cab / Cw / N: mueven SOLO el gemelo (tu hipótesis sobre la hoja). Cab = clorofila (µg/cm²), Cw = agua (cm), N = estructura (1 fina – 2,5 gruesa).
  • Reajustar gemelo a la hoja: vuelve a alinear tu hipótesis con la hoja simulada tras un experimento.
  • Modo óptico: reflectancia o transmitancia. El ML solo funciona en reflectancia (así se entrenó).
  • Estrés simulado: aplica una firma de estrés a la hoja (cae el NIR, sube el rojo, baja el verde) para ver cómo salta la anomalía.

Prueba guiada (2 minutos)

  1. Observa el gráfico: barras y línea casi superpuestas, error relativo ~2–5 %, sin aviso.
  2. Sube el slider Cab a 70: la predicción cambia pero la hoja no → el error supera el 10 % y aparece «Posible anomalía». Eso es una discrepancia modelo–medida, no un diagnóstico automático.
  3. Pulsa Reajustar: todo vuelve a coincidir.
  4. Activa el estrés y mira cómo caen NIR y F5.

Límites honestos

  • Sin hardware real: el ESP32 aún no está conectado.
  • El índice 0–100 y el Cab ML son estimaciones sobre simulaciones, no medidas de campo.
  • El sensor no estima agua con fiabilidad (banda de 910 nm poco sensible) ni permite recuperar Cab, Cw y N de forma única.
  • PROSPECT-D está contrastado contra el paquete R de los autores (diferencia ~2e-15); eso valida el código, no el sensor.
